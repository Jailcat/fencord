# Fencord

Fencord is Vencord but for [Fenrid.com](https://fenrid.com). It is a client mod for Fenrid and fully open source. It has been public since week one of Fenrid.com's waitlisted alpha.

## Install

Download the latest `fencord.exe` from [Releases](https://github.com/Jailcat/fencord/releases) and run it. No install needed.

## What it does

- Loads Fenrid.com as a standalone desktop app
- Injects the Fencord userscript automatically
- Auto-updates the script from GitHub on every launch
